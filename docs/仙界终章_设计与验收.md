# 仙界终章：证道之后，回望此生

证道后，主面板和行动区出现“回望此生”。先看两界实录、终章与题记，再选择“继续行走两界”或“就此封卷，为此生立传”。封卷有独立确认，确认说明和按钮固定展示，长文在中间滚动。

- 查看不推进时间、不发钱、不涨修为或功绩，不完成心愿，不改亲友生死、关系。
- 无须额外完成入仕、一统、婚恋或收徒。独行、未立派、无亲友记录的局同样能收束。
- 不联网也有依据当前实录生成的完整回顾；“续写此生终章”才使用原有模型接口润色。失败保留实录与已有文字，可重试。
- 健在亲友按当前所在界展示，已故者据实记已故，不替他们安排未来生死或飞升。
- 证道结果所在回合尚待重试、结清或恢复显示时，终章入口不可用；结清后可查看，不自动封卷。
- v12/v13/v14 旧证道档只有主动入口，加载不自动弹终章、不自动结束。已结束旧档保留原传记与结局。
- 存档键 `xian_save_v1`、版本 14 保持不变。`daoEnding` 只保存终章文字缓存、来源快照及封卷凭据，沿用现有 `bio`、保存队列和史册；没有新增境界、资源、任务、奖励或结局积分。

## 防重与保存

查看和续写不进入回合结算函数。只有二次确认才设置结束状态；先等待主档落盘，再按稳定的本局凭据写史册。连续点击、重试、保存读档、恢复封卷前的同一局不会重复入册。

主档保存失败时恢复为未结束，不写史册。若主档已封卷、史册写入失败，则保留传记，可在“重看终章”中核对补记；重复核对仍只保留一条。损坏的旧史册不覆盖或清空。健在证道者的史册年龄标为“封卷时”，不用“享年”。旧统计缺项沿用原评分公式按零处理。

终章正文存于传记，恢复时只渲染，避免再次结算或重复写章节。导出全本会附上封卷终章一次。证道面板不再显示 0/0 或零月冲满倒计时，仍可调息和继续游历。
